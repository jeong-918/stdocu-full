학생 정보, 세특 정밀 진단, 누적 서사, 2022 주제탐구 설계 및 상담 메모는 브라우저 로컬 스토리지에 즉시 저장되어 새로고침 후에도 유지됩니다.

JSON 파일 백업 및 복원

기기를 변경하거나 PC에 별도 보관할 때 전체 데이터를 JSON 파일로 내보내거나 복원할 수 있습니다. (v1.0 / v2.5 백업 파일도 자동 이관 지원)

GitHub 자동 동기화 (기기 간 데이터 이동)

Fine-Grained Access Token을 입력하고 자동 백업을 켜면 수정 내역이 지정한 저장소의 JSON 파일로 5초 뒤 자동 업로드되며, 다른 기기에서 페이지를 열 때 최신 데이터를 자동으로 가져옵니다.

기존에 발급받은 저장소용 토큰을 그대로 사용하실 수 있습니다. 토큰은 현재 브라우저에만 저장됩니다.
마지막 업로드: 기록 없음

AI API 연동 설정 (선택 기능)

API 없이도 모든 탭에서 「프롬프트 복사 → 채팅(스킬) 분석 → 결과 붙여넣기」로 100% 오프라인 작동합니다.
